# Código de conduta

Colaboradores devem agir com respeito, clareza e responsabilidade técnica.

- Discuta problemas e decisões, não pessoas.
- Não publique segredos, dados pessoais ou material protegido.
- Apresente evidências reproduzíveis para bugs e mudanças de comportamento.
- Respeite o escopo aprovado e sinalize mudanças de escopo antes de implementá-las.
- Não faça uso abusivo de serviços, APIs, harnesses ou infraestrutura de terceiros.

Comportamento abusivo, discriminatório, ameaçador ou deliberadamente enganoso
não é aceito. Relatos devem ser enviados de forma privada aos mantenedores.
