# AI Knowledge Base — Gemini CLI

Antes de agir, leia `BOOTSTRAP.md`. Consulte a skill aplicável em `skills/`, o
`SPEC.md` e as referências somente quando a tarefa exigir. Não construa sem
spec aprovado, mapa de ferramentas e etapa curta autorizada.

Para compatibilidade com este harness, trate `run_shell_command` como execução
de comandos, leitura do workspace como inspeção do repositório e os arquivos
Markdown como fonte de contexto. Não invente ferramentas equivalentes.
