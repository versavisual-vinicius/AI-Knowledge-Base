# Segurança

## Escopo

Este repositório contém instruções, documentação, scripts de validação e
adapters. Ele não deve receber tokens, chaves, cookies, transcripts brutos ou
dados pessoais.

## Relato responsável

Não publique segredos ou detalhes exploráveis em issues públicas. Para um risco
de segurança, abra um relato privado pelo mecanismo de Security Advisories do
GitHub, quando disponível, ou contate os mantenedores antes de divulgar o
problema.

Inclua apenas o contexto mínimo para reproduzir o problema e remova credenciais
e dados pessoais dos anexos.

## Limites

Os adapters não concedem permissões por conta própria. O usuário deve revisar
hooks, scripts e plugins antes de instalar, especialmente em harnesses que
executam código local com as permissões do usuário.
